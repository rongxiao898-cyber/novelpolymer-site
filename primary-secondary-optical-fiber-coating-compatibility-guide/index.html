COATING SYSTEM GUIDE

Primary and Secondary Fiber Coating Compatibility

Primary and secondary coatings perform different functions, but their interface and shared process window determine whether the dual-layer system can be manufactured and qualified consistently.

Send your application briefView all technical guides
01

Define the function of each layer

Document which layer provides the compliant interface around the glass and which provides external protection. Set separate material and finished-fiber criteria for those roles.

02

Map the wet-on-wet process

Record application order, material temperature, concentricity control, layer dimensions and the time between coating and cure. Evaluate the actual sequence used on the draw line.

03

Characterize the cure sequence

Document UV source conditions, line speed, atmosphere and how the primary and secondary layers receive exposure. A nominal lamp setting alone does not establish cure compatibility.

04

Check the coating interface

Inspect layer continuity, adhesion, surface condition and dimensional stability using agreed methods. Include aging or conditioning when it is relevant to the finished construction.

05

Qualify the finished fiber

Use optical, mechanical, environmental and handling tests on fiber made with the intended glass, dimensions and line process rather than relying on bulk material data alone.

TECHNICAL FAQ

Questions to clarify before evaluation

Can primary and secondary coatings be selected independently?

Their individual properties matter, but the interface, cure sequence and finished-fiber performance should also be evaluated as one system.

Why is the draw-line sequence part of compatibility?

Application timing, geometry, UV exposure and atmosphere can affect the interface and the cure state of both layers.

What should be compared between coating systems?

Compare materials under matched test conditions and then qualify the complete coated fiber using the intended process and acceptance tests.
