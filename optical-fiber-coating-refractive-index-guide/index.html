MEASUREMENT GUIDE

How to Specify Refractive Index for Optical Fiber Coatings

A refractive-index value is meaningful only when its measurement conditions and its role in the fiber design are clearly defined.

Discuss your applicationView all technical guides
01

State the measurement wavelength

Refractive index changes with wavelength, so values measured at different wavelengths should not be treated as directly interchangeable.

02

Record the measurement temperature

Temperature affects refractive-index results. Include the measurement temperature whenever a target or supplier value is quoted.

03

Identify the material state

Clarify whether the value refers to the uncured liquid, a cured film or another prepared specimen. The liquid value does not automatically represent the cured coating.

04

Use a consistent method

Instrument, specimen preparation and test procedure can affect the result. Compare materials using an agreed and repeatable method.

05

Connect the value to the fiber architecture

For active, double-clad, medical or light-delivery fibers, define where the coating sits and what optical function it must support in the finished structure.

INFORMATION CHECKLIST

Prepare these details for a productive material discussion.

  • Target wavelength
  • Measurement temperature
  • Liquid or cured material state
  • Instrument and test method
  • Fiber architecture and optical function

TECHNICAL FAQ

Questions to clarify before evaluation

Can liquid and cured refractive-index values be compared directly?

They describe different material states and should be identified separately.

Why must wavelength be included?

Refractive index varies with wavelength, so the measurement wavelength is required for a meaningful comparison.

Is refractive index alone enough to select a coating?

No. Cure behavior, coating process, mechanical requirements and finished-fiber validation also matter.
