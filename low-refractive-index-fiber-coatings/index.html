TECHNICAL FAQ

Questions for application planning

How should a refractive-index requirement be specified?

State the wavelength, temperature and whether the value refers to the liquid or cured material.

How do I choose between TZ-136 and TZ-140?

Begin with the fiber architecture and target refractive index. The two products address different application groups and should be evaluated in the intended fiber process.

Does the medical-fiber application description establish device certification?

No. It identifies an intended fiber application. Qualification of the finished device remains application-specific.
